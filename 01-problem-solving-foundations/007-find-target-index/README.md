# Problem 007: Find the Index of a Target Number

**Difficulty:** Easy

**Category:** Searching / Problem-Solving Foundations

**Algorithm:** Linear Search

**Language:** Python

## Problem Statement

Given a list of integers and a target number, find the index of the target's first occurrence without using Python's built-in `index()` method.

If the target does not exist in the list, return `-1`.

## Learning Objectives

- Understand Python list indexing.
- Practice defining and calling functions.
- Learn index-based iteration using `range()` and `len()`.
- Understand the difference between a value and its index.
- Apply linear search to locate an element.
- Understand early returns and loop control.
- Analyze time and auxiliary space complexity.

## Example

**Input:**

```python
numbers = [10, 25, 30, 45, 30, 50]
target = 30
```

**Output:**

```text
Target Index: 2
```

## Approach

1. Define a function named `find_target_index()` that accepts a list and a target.
2. Iterate through the list using index positions generated by `range(len(numbers))`.
3. Access each element using `numbers[index]`.
4. Compare the current element with the target.
5. If a match is found, return the current index immediately.
6. If the loop finishes without finding a match, return `-1`.

## Solution

```python
def find_target_index(numbers, target):

    for index in range(len(numbers)):
        if numbers[index] == target:
            return index

    return -1


numbers = [10, 25, 30, 45, 30, 50]
target = 30

result = find_target_index(numbers, target)

print(f"Target Index: {result}")
```

## How It Works

The function checks each element using its index.

- Index `0`: Value is `10`, no match.
- Index `1`: Value is `25`, no match.
- Index `2`: Value is `30`, match found.

The function immediately returns `2`.

Because the function returns the first matching index, it does not continue searching for later occurrences.

## Mistakes Encountered and Corrections

### Mistake 1: Confusing values with indexes

The initial implementation attempted to use the target value as a list index.

**Correction:** Use an index variable to access elements and compare their values with the target.

### Mistake 2: Incorrect list indexing

The initial implementation attempted to use the current number as an index.

**Correction:** Access list elements using a valid index generated by `range(len(numbers))`.

### Mistake 3: Returning too early

The initial implementation returned `-1` inside the loop after the first unsuccessful comparison.

**Correction:** Place `return -1` outside the loop so that every element can be checked before reporting that the target is absent.

## Complexity Analysis

**Best-case Time Complexity: O(1)**

The target is found at the first index.

**Average-case Time Complexity: O(n)**

The algorithm may check several elements before finding the target.

**Worst-case Time Complexity: O(n)**

The target is at the last index or does not exist.

**Auxiliary Space Complexity: O(1)**

The algorithm uses a constant amount of additional memory.
