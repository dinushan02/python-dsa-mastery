## 🧠 My Problem-Solving Method

For every problem, I aim to follow this process:

1. **Understand:** Read the problem carefully and identify what is required.
2. **Analyze:** Identify inputs, outputs, constraints, and edge cases.
3. **Plan:** Develop a logical approach before writing code.
4. **Implement:** Write the Python solution independently.
5. **Test:** Check normal inputs, boundary cases, and relevant edge cases.
6. **Debug:** Identify errors and understand why they occurred.
7. **Analyze complexity:** Evaluate time and auxiliary space complexity.
8. **Improve:** Refactor the solution for readability and efficiency.
9. **Document:** Explain the approach, complexity, tests, and lessons learned.
10. **Commit:** Save progress using meaningful Git commits and push it to GitHub.

## ⏱️ Complexity Analysis

I will gradually learn to recognize common complexity classes:

| Complexity | Meaning |
|---|---|
| O(1) | Constant time |
| O(log n) | Logarithmic time |
| O(n) | Linear time |
| O(n log n) | Linearithmic time |
| O(n²) | Quadratic time |
| O(2ⁿ) | Exponential time |

I will learn how input size affects runtime and memory usage, and how to compare different approaches to the same problem.
